\## \[1.0.0] - 2026-09-20



\### Added

\- Initial public release of `OldGamesDownload-Windows-Crawler`.

\- Python-based crawler for the OldGamesDownload Windows catalog.

\- Extraction of game metadata from catalog pages.

\- Extraction of Windows file metadata.

\- Capture and storage of MediaFire mirror URLs.

\- SQLite persistence for crawled game, file, and mirror records.

\- Hydra-compatible JSON catalog export.

\- Basic project structure, documentation, and usage instructions.
